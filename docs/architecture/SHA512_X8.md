# Eight-lane SHA-512 compression

## Current boundary

The low-level ABI-zero seam applies one SHA-512 compression block to eight
independent, already-transposed states. A second ABI-zero entry computes the
exact verifier hash `SHA512(original_R || original_A || message)` with unequal
message lengths and active masks. Its initial transparent C scheduler keeps
pointer gathering, byte order, padding, tails, and completion capture visible
while every compression block enters the native x8 assembly leaf.

`state.word[i][lane]` is state word `i` for lane `lane`.
`block.word[i][lane]` is the numeric value of SHA message word `i`; raw input
bytes therefore require a big-endian load during transposition.

## Native schedule

The assembly retains the sixteen most recent message words in ZMM16..ZMM31
and updates them as a ring. Working variables `a` through `h` rotate through
ZMM0..ZMM7 by macro argument selection, avoiding register moves. Boolean
functions use `VPTERNLOGQ`; every operation remains lane-local.

The leaf has no stack frame. RDX, rather than callee-saved R12 used by the Go
ABI source, holds the round-constant pointer under System V AMD64. This is an
ABI-relevant translation detail, not an arithmetic change.

## Assurance gates

- GNU/Clang x86-64 assembly parser;
- a fail-closed [source-schedule certificate](../proofs/SHA512_SOURCE_SCHEDULE.md)
  covering all constants, rotations, ternary truth tables, eighty working
  register maps, sixty-four rolling-ring expansions, and feed-forward stores;
- the FIPS SHA-512 digest of the empty message;
- 2,000 deterministic random states and blocks checked against a scalar
  eighty-word-schedule implementation;
- all 256 active masks over messages spanning SHA padding boundaries and
  lengths 0, 1, 47, 48, 64, 200, 1232, and 4096 bytes;
- an external known answer for SHA-512 over 64 zero bytes;
- all eight lanes populated independently;
- native Zen execution, warning-as-error compilation, ASan, and UBSan.

The next performance layer will replace the transparent per-block C
transposition with audited first/middle/final assembly shapes. It must remain
bit-identical to this scheduler, including original `R`/`A` bytes, SHA-512's
128-bit length and padding rules, every active mask, and unequal lengths.
