# Security policy

Narya Ed25519 Assembly is alpha, incomplete, unaudited, and not suitable for
production or consensus use.

Please report suspected security or consensus issues privately to the
Overclock Validator maintainers rather than opening a public issue with an
exploit or unpublished test vector. Include the source commit, CPU, compiler,
minimal reproducer, expected and observed verdicts, and whether Go Narya or
another pinned implementation disagrees.

No release is currently covered by a production support or embargo guarantee.
This file will name a dedicated reporting address before the first public
security-reviewed release.
