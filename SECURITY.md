# Security policy

Narya Ed25519 Assembly is alpha, incomplete, unaudited, and not suitable for
production or consensus use.

When **Report a vulnerability** is visible under this repository's
**Security** tab, use it to submit suspected security or consensus issues
through GitHub Private Vulnerability Reporting. Until an organization owner
enables that repository setting, contact an Overclock Validator organization
owner through GitHub without including sensitive details and request a private
reporting channel. Do not open a public issue containing an exploit or
unpublished test vector.

Include the source commit, CPU, compiler, minimal reproducer, expected and
observed verdicts, and whether Go Narya or another pinned implementation
disagrees. Never include credentials, production keys, or unrelated user data.

No release is currently covered by a production support, response-time, bounty,
or embargo guarantee. Private Vulnerability Reporting or a dedicated role
address must be active before the first security-reviewed release.
